# CS50AI Implementations

A consolidated repository of my Harvard CS50AI projects, focused on decision modeling, search algorithms, knowledge representation, probabilistic reasoning, and neural network architectures built from first principles.

---

## Projects Directory

### Search
* degrees — Breadth-First Search algorithm to determine degrees of separation between actors.
* tictactoe — Minimax algorithm with Alpha-Beta Pruning for an optimal game agent.

### Knowledge
* knights — Propositional logic and knowledge engineering for solving logical puzzles.
* minesweeper — Knowledge-based agent utilizing propositional logic inferences.

### Uncertainty
* pagerank — PageRank implementation using Random Surfer and Iterative algorithms.
* heredity — Bayesian Networks to model gene inheritance probabilities.

### Optimization
* crossword — Constraint Satisfaction Problem solver using arc consistency and backtracking.

### Learning
* shopping — Supervised learning using a k-Nearest Neighbors classifier to predict user behavior.
* nim — Reinforcement learning agent trained via Q-learning.

### Neural Networks
* traffic — Deep Convolutional Neural Networks for image classification.

### Language
* parser — Natural Language Processing using Context-Free Grammar parsing with NLTK.
* attention — Transformer attention layer visualization and BERT mask extraction.
